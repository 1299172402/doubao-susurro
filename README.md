# [Doubao Susurro](https://github.com/1299172402/Doubao-Susurro) – 开源跨设备输入工具

> **Susurro** (西语) — [suˈsuro] — *名词*：低语、沙沙声、窸窣
>
> 像风拂过树叶的低语，让文字在设备间悄然流动。

开源跨设备输入工具，依托手机豆包应用即可使用，无需额外安装程序。手机书写、口述的文字可一键直传电脑任意输入框，顺畅衔接日常办公与创作流程。

## 🎯 适用场景

- **代码辅助输入**：适配 OpenCode、Claude Code 等命令行编程工具，接入语音快速输入。

  <details>
  > 谁不喜欢多一种输入方式呢？多一种输入方式就是多一种选择
  </details>

- **低噪轻声录入**：办公室、图书馆、夜间宿舍等安静场景，对着手机小声说话即可识别，不会出声打扰他人。

  <details>
  > 豆包在这一点感觉特别好，在豆包中跟它语音说话，我有些时候甚至声带都不震动，我只是发出气流音，它也能够捕捉到。对我来说呢，能减轻不少我对别人的打扰。
  </details>

- **长辈简易录入**：无需专属软件与驱动，手机直接充当手写板；也不用掌握拼音、不必操作电脑自带手写功能，长辈轻松手写，上手即用。

  <details>
  > 虽然我常用语音输入，但是它有一个痛点，就是它识别不准确。虽然我能理解它在可能 99% 的情况下，或者甚至 99.7% 以上的情况下他能有很高的正确率，但是对我来说，我或者我的家里人在编辑文档或者是编辑些重要事情的东西的时候，对他们来说他们对错别字的要求是 0，至少在我认识的字里面不能出现错别字，这是语音输入目前还没有能够达到的目标。那为什么又需要用手机当手写板呢？因为其实很多父母他们虽然就是不会用拼音，但是他们会手写，这个手写大家都会。然后呢我能把手写字通过豆包发送到电脑上去，这样也能让他们把文字全部给它一笔一画的写出来。这对我来说也是一个比较有用的功能。
  </details>


- **独立语音端口**：在电脑播放音乐、开会通话中，手机可作为独立的录音与输入入口，录入文字不会中断或干扰你正在使用的音频与麦克风。 

  <details>
  > 这里其实我也在用豆包输入法的 Windows 下的电脑版（这里感谢字节的同学），但是对我来说它有一个痛点，就是我按下 右Alt，它会不一定能够输入成功，这是第一点，它有概率性的问题，它有时候能成功，有时候失败，我不知道是什么原因，但是很频繁出现，这对我来说有一点打断。第二点呢就是当我比如说戴着耳机听音乐，或者是我在开会的时候，嗯我摁下这个 Alt 键，它不一定能够成功识别到我的声音，有时候会卡死，我一定要先切换到微软输入法，再切回来才能再接着用，或者就干脆它连那个声波的那个图标它都弹不出来了。对我来说也比较讨厌，但是手机对我来说它的识别成功率就几乎是 100% 。而且对我来说，我有些时候也会配合着用。比如说我手机上用豆包输入法，再加上它的智能整理，它就能把文字整理好之后发送到我的输入框中。这样对我来说也很方便。
  </details>

## ✨ 核心亮点

- **高精度语音转文字**：支持嘈杂环境、自动添加标点符号、中英文混合输入。
- **实时同步**：自动写入系统剪贴板，需要时按 <kbd>Ctrl</kbd>+<kbd>V</kbd> 即可粘贴。
- **自动输入模式**：启用后，光标定位到输入框即可直接填入文字，省去手动粘贴。
- **后台托盘运行**：静默不打扰，随时可用。
- **网页可视化配置**：无需手动修改配置文件。
- **静默启动 & 开机自启**：支持 Windows / Linux / macOS。

### 🚀 快速上手

1.  **获取配置文件**：
    * 打开 [豆包网页版](https://www.doubao.com)，登录并进入一个对话。
    * 按 <kbd>F12</kbd> 打开开发者工具 → **Network**（网络）标签。
    * 点击网页中的任意一个对话 → 在 **Network**（网络） 中寻找最新一条 `single`（`https://www.doubao.com/im/chain/single`）请求。
    * 右键该请求 → **Copy** → **Copy as cURL (Bash)**。

2.  **启动并配置**：
    * 双击运行 `Doubao-Susurro.exe`，浏览器会自动打开配置页面。
    * 将复制的 cURL 内容粘贴进去，点击「💾 保存配置」。
    * 点击「🚀 获取消息」测试一下是否正常。

3.  **开始使用**：
    * 现在，在你的手机上，对着豆包的**同一个对话**说话或手写。
    * 回到电脑，打开记事本或任何输入框，按下 <kbd>Ctrl</kbd>+<kbd>V</kbd> 即可看到刚才输入的文字！
    * 对于“自动输入”，只要光标在输入框内，然后对手机豆包说话，文字就会直接显示在输入框中。
